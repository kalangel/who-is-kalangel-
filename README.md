# who is kalangel

Сайт-аттракцион. Направление — **«Затмение»**: тело закрывает светило, видно
только то, что утекает по краю. Это тело — чёрная дыра, и к финалу она съедает
всё, включая имя.

Арт-дирекция и технические решения зафиксированы в **[docs/eclipse-spec.md](docs/eclipse-spec.md)**.
Спека — контракт: если вопроса в ней нет, он выносится в обсуждение, а не
решается по ходу.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173/ru/
npm run build    # tsc --noEmit + vite build → dist/
npm run preview
```

## Устройство

```
index.html            корень: определяет язык по браузеру и перебрасывает
en|ru|de/index.html   тонкие страницы: lang, title, мета
src/gl/scene.frag.glsl  вся сцена: геодезики фотонов, диск, небо, фотосфера
src/gl/renderer.ts      раскадровка и проходы кадра, наружу отдаёт setPhase(p)
src/gl/gl.ts            обвязка над WebGL2: программы и цели рендера
src/gl/*.frag.glsl      блум и сведение
src/mark.ts             маска марки для созвездия
src/wordmark.ts       ВРЕМЕННЫЙ логотип (см. ниже)
src/content/*.json    тексты трёх языков
src/styles.css        токены и вёрстка
src/fonts/            самохостящиеся Prata + IBM Plex Mono
```

Языки переключаются **только адресом** — `/ru/`, `/en/`, `/de/`. Переключателя
в интерфейсе нет by design.

## Скролл

Страница — не лента секций, а **скраббер**: сцена приколочена к экрану, скролл
проматывает по ней время. Тринадцать экранов прокрутки проводят восемь актов —
от затмения через раскрытие дыры, падение и вспышку к поверхности гиганта,
отъезду до созвездия из ника и обратно к горизонту событий.

Режиссура — `motion`, вся в `src/timeline.ts`; инерция скролла — `lenis`. Рендер
о скролле не знает ничего, кроме одного числа: `renderer.setPhase(p)`.

## Рендер

WebGL2, один полноэкранный фрагментный шейдер. Фотоны трассируются по
геодезическим Шварцшильда: тень, кольцо, изгиб фона и допплеровский перекос
диска не нарисованы, а посчитаны. Сведение — HDR, блум в два радиуса,
анаморфный след, ACES, зерно.

Разрешение динамическое: при просадке кадра масштаб рендера падает. Лучше отдать
резкость, чем частоту.

## Механика

Указатель и палец слегка доворачивают камеру. Это единственный интерактив на
странице и единственная причина, по которой кадр у двух посетителей разный.

## Что осталось сделать

**1. Настоящий логотип.** Сейчас стоит заглушка `src/wordmark.ts`: центральная
звезда и боковые искры собраны геометрически точно, а само слово набрано
серифом-заменителем и не повторяет оригинальное готическое начертание.
Оригинал существует только растром в переписке — файла в репозитории нет.

Чтобы поставить настоящий: положить в `public/` файл с именем `wordmark.svg`,
`wordmark.png` или `wordmark.webp` (годится и `logo.*`). Он подхватится сам — и
в вёрстке первого акта, и в маске созвездия; источник у них один, разъехаться
они не могут. Радиус кольца затмения пересчитается сам: он выводится из ширины
логотипа.

Требований к файлу почти нет:

* **Цвет не важен.** Марка идёт маской и красится цветом сайта — чёрный логотип
  на прозрачном фоне подхватится так же, как белый.
* **Поля не важны.** Пустые края обрезаются, марка растягивается на всю
  отведённую ширину.
* **SVG: текст переведи в кривые.** Иначе растеризация в маску потеряет шрифт и
  соберёт созвездие не из тех букв.
* **PNG/WebP: лучше от 2000 px по ширине** и с прозрачным фоном.

Если файл не подхватился — причина уходит в консоль одной строкой
(`[kalangel] логотип: …`), а на экране остаётся заглушка. Самое частое: у SVG
нет `width`/`height` в корне — такой файл Safari растеризует в ноль на ноль.
Это чинится автоматически, но если в консоли написано другое, там же написано
и что делать.

**2. Ссылка на Telegram.** Единственное целевое действие сайта. Впиши URL в
`TELEGRAM_URL` в `src/main.ts` — CTA в финальном такте сам станет ссылкой.
Пока константа пуста, он остаётся текстом: мёртвая ссылка хуже её отсутствия.

**3. Домен и деплой.** `base: './'` в конфиге, так что сборка работает и на
GitHub Pages в подпапке, и на своём домене без изменений.

## Шрифты

Prata (заголовки) и IBM Plex Mono (подписи) — оба SIL Open Font License 1.1,
лежат локально в `src/fonts/`. Выбраны в том числе потому, что **покрывают
кириллицу**: изначально заявленные Instrument Serif и Space Mono только
латинские, и русская версия сваливалась на Times.
