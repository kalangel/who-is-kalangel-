# who is kalangel

Сайт-аттракцион. Направление — **«Затмение»**: объект закрывает светило, видно
только то, что утекает по краю.

Арт-дирекция и технические решения зафиксированы в **[docs/eclipse-spec.md](docs/eclipse-spec.md)**.
Спека — контракт: если вопроса в ней нет, он выносится в обсуждение, а не
решается по ходу.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173/ru/
npm run build    # tsc --noEmit + vite build → dist/
npm run preview
```

## Устройство

```
index.html            корень: определяет язык по браузеру и перебрасывает
en|ru|de/index.html   тонкие страницы: lang, title, мета
src/eclipse.ts        рендер затмения, наружу отдаёт setPhase(p)
src/corona.ts         генератор текстуры короны
src/wordmark.ts       ВРЕМЕННЫЙ логотип (см. ниже)
src/content/*.json    тексты трёх языков
src/styles.css        токены и вёрстка
src/fonts/            самохостящиеся Prata + IBM Plex Mono
```

Языки переключаются **только адресом** — `/ru/`, `/en/`, `/de/`. Переключателя
в интерфейсе нет by design.

## Механика

Указатель и палец задают направление света: тело уходит от посетителя, свет
прорывается с обратной стороны, корона съезжает в сторону свечения. Это
единственный интерактив на странице и единственная причина, по которой кадр
у двух посетителей разный. Подробности — раздел 5a спеки.

## Что осталось сделать

**1. Настоящий логотип.** Сейчас стоит заглушка `src/wordmark.ts`: центральная
звезда и боковые искры собраны геометрически точно, а само слово набрано
серифом-заменителем и не повторяет оригинальное готическое начертание.
Оригинал существует только растром в переписке — файла в репозитории нет.

Чтобы поставить настоящий: положить `wordmark.svg` в `public/` и заменить
содержимое `#wordmark` на `<img src="./wordmark.svg" alt="kalangel">`.
Радиус кольца пересчитается сам — он выводится из ширины логотипа.

**2. Скролл-таймлайн на Motion** — единственная невыполненная анимация.
Рендер уже разведён с режиссурой: наружу торчит один метод.

```bash
npm i motion
```

```ts
import { scroll } from 'motion'
scroll(({ y }) => eclipse.setPhase(y.progress))
```

Пока таймлайна нет, `phase` зафиксирована на `0.5` — полная фаза. Кадр живой за
счёт вращения короны, но по скроллу не меняется.

**3. Ссылка на Telegram** — целевое действие, встаёт в финальную фазу выхода.

**4. Домен и деплой.** `base: './'` в конфиге, так что сборка работает и на
GitHub Pages в подпапке, и на своём домене без изменений.

## Шрифты

Prata (заголовки) и IBM Plex Mono (подписи) — оба SIL Open Font License 1.1,
лежат локально в `src/fonts/`. Выбраны в том числе потому, что **покрывают
кириллицу**: изначально заявленные Instrument Serif и Space Mono только
латинские, и русская версия сваливалась на Times.
